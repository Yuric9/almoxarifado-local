# Almoxarifado Local

Aplicativo local e portátil para gestão de estoque, com banco de dados local.

## Direção do projeto

- Funcionamento offline
- SQLite como persistência local
- Aplicativo Windows instalável e portátil
- Backup e restauração do banco
- Manutenção do schema compatível com a futura versão online

## Retomar versão online

O projeto preserva a referência ao modelo Supabase e deverá conter `ONLINE-MIGRATION.md` durante a migração para documentar a retomada da versão online.
